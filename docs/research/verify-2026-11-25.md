## 3. Client pays in any asset, freelancer gets exact USDC

| Finding | Source |
|---|---|
| A classic payment or path payment **cannot** use a contract (C...) address as destination. The freelancer wallet and the split contract are both C addresses. | https://developers.stellar.org/docs/build/guides/transactions/send-and-receive-c-accounts |
| A classic and a Soroban operation cannot share one transaction. | Stellar transaction rules |
| Testnet XLM/USDC liquidity is deep: a live order book plus one classic AMM pool holding about 97.9M XLM and 63.8M USDC. | Horizon testnet `/order_book`, `/liquidity_pools` |
| Soroswap has a testnet aggregator `CC74XDT7UVLUZCELKBIYXFYIX6A6LGPWURJVUXGRPQO745RWX7WEURMA` and router `CCJUD55AG6W5HAI5LRVNKAE5WDP5XGZBUDS5WNTIVDU7O264UZZE7BRD`. Its pool liquidity was not checked. | github.com/soroswap |

**Proposed (needs Joshua):** two signatures from the client's wallet.
1. A classic `path_payment_strict_receive` to the client's own account: XLM in, exact USDC out, through the Stellar DEX. It adds a USDC trustline first if the client lacks one.
2. `split.deposit(from = client, amount, invoice_ref)`: the contract pulls the USDC and splits it.

This keeps the classic DEX path payment that the brief names. The alternative is one atomic Soroban call through Soroswap, which depends on third-party testnet liquidity.

## 4. Invoice reference

Soroban transactions must use `MEMO_NONE`. Since CAP-67, a SAC `transfer` accepts a muxed `to`, but the muxed id appears only in the event and the receiving contract cannot read it.

**Decision:** the invoice reference is a `deposit` argument and is emitted in the `split` event. The indexer matches events to invoices exactly.

## 6. Naira rate (Reflector)

The Reflector FX oracle on testnet (`CCSSOHTBL3LEWUCBBEB5NJFC2OKFRC74OWEIJIZLRJBGAAU4VMU5NV4W`) lists EUR, GBP, CHF, CAD, MXN, ARS, BRL, THB and XAU, with base USD. It has **no NGN and no USDC**, checked by simulating `assets()`.

**Decision (allowed by the brief):** use the CBN official NFEM rate as the statutory rate, labelled with its source. CBN publishes it as an HTML table at https://www.cbn.gov.ng/rates/ExchRateByCurrency.html and offers no API. The rate sits behind an oracle-shaped interface (`priceOf(asset, date)`), so a Soroban NGN feed can replace it later. DIA runs a non-SEP-40 oracle on testnet, but no live NGN feed was confirmed.
